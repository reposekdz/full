# 🎓 GARDEN TVET - COMPLETE API & FEATURES DOCUMENTATION

## 🚀 Quick Start

### Option 1: Full Build & Run (First Time)
```bash
BUILD-AND-RUN-ALL.bat
```
This will:
- Install all dependencies (backend + frontend)
- Build the frontend
- Start both servers
- Open the application in your browser

### Option 2: Quick Start (Dependencies Already Installed)
```bash
QUICK-START-SERVERS.bat
```
This will:
- Start backend server on port 5000
- Start frontend server on port 5173
- Open the application in your browser

### Option 3: Check System Status
```bash
CHECK-SYSTEM-STATUS.bat
```
This will verify:
- Node.js installation
- Dependencies status
- Database connection
- Port availability

### Option 4: Test All APIs
```bash
TEST-ALL-APIS.bat
```
This will test all API endpoints and show success rate.

## 📝 Notes

1. **First Time Setup**: Run `BUILD-AND-RUN-ALL.bat` to install all dependencies
2. **Quick Start**: Run `QUICK-START-SERVERS.bat` if dependencies are already installed
3. **System Check**: Run `CHECK-SYSTEM-STATUS.bat` to verify system status
4. **API Testing**: Run `TEST-ALL-APIS.bat` to test all endpoints
5. **Database**: Make sure MySQL is running and configured in `backend/.env`
6. **Ports**: Backend uses port 5000, Frontend uses port 5173
7. **Auto Port Selection**: If port 5000 is busy, backend will try 5001, 5002, etc.
