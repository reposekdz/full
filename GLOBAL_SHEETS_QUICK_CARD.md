# 🎯 Global Student Sheets - Quick Reference Card

## ⚡ **30-SECOND GUIDE**

### **Access**
```
DOS/Headmaster Dashboard → "Abanyeshuri" Tab → Global Student Sheets
```

### **8 Student Actions**
| Icon | Action | Permission | SMS |
|------|--------|------------|-----|
| 🔗 | Link Parent | All Staff | ✅ |
| 💬 | Send SMS | All Staff | ✅ |
| 🚫 | Remove Conduct | DOS/DOD/Headmaster | ✅ |
| ✅ | Grant Leave | DOS/DOD/Headmaster | ✅ |
| 📞 | Call Parent | All Staff | ❌ |
| 📧 | Email Parent | All Staff | ❌ |
| 👁️ | View Details | All Staff | ❌ |
| ✏️ | Edit Student | All Staff | ❌ |
| 🗑️ | Delete Student | DOS/Headmaster | ❌ |

### **4 Bulk Actions**
- **Send SMS** - Custom message to all selected
- **Remove Conduct** - Bulk conduct removal
- **Grant Leave** - Bulk leave approval
- **Export Excel** - Export selected students

### **Add New Student (DOS/Headmaster Only)**
1. Click "Add Student" button
2. Fill: First Name, Last Name (required)
3. Optional: Email, Phone, DOB, Address
4. Click "Add Student"

### **Quick Filters**
- **Search** - Type name or code
- **Conduct** - Slider 0-40
- **Payment** - Paid/Pending/Overdue
- **Gender** - Male/Female/All

### **Keyboard Shortcuts**
- `Ctrl+F` - Focus search
- `Ctrl+A` - Select all
- `Ctrl+E` - Export Excel

## ⚡ **Common Tasks**

### Send SMS to Multiple Students
1. Check boxes to select students
2. Click "Send SMS" in bulk actions bar
3. Enter message
4. Confirm

### Remove Conduct from Student
1. Click 🚫 icon on student row
2. Enter points to remove (1-40)
3. Enter reason
4. Confirm (Parents notified automatically)

### Add New Student
1. Click "Add Student" button (DOS/Headmaster only)
2. Fill required fields (First Name, Last Name)
3. Select Gender, enter optional fields
4. Click "Add Student"

### Export Students to Excel
1. Select students (or leave empty for all)
2. Click "Export" button
3. File downloads automatically

## 🐛 **Quick Fixes**

### No Students Showing
- Check trade/level selection
- Verify database has students
- Refresh page (F5)

### Action Not Working
- Check your role permissions
- Verify backend is running
- Check browser console

### SMS Not Sending
- Verify parent is linked
- Check phone number format
- Contact admin
