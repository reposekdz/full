## 🧮 Calculation Flow

```
┌─────────────────────────────────────────────────────────────┐
│                    CALCULATION ENGINE                        │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  INPUT: Student Marks                                        │
│  ┌────────────────────────────────────────────────────┐    │
│  │ Test 1: 18/20 (Weight: 20%)                        │    │
│  │ Test 2: 16/20 (Weight: 20%)                        │    │
│  │ Exam:   54/60 (Weight: 60%)                        │    │
│  └────────────────────────────────────────────────────┘    │
│                                                              │
│  STEP 1: Calculate Weighted Scores                          │
│  ┌────────────────────────────────────────────────────┐    │
│  │ Test 1: (18/20) × 20 = 18.00                       │    │
│  │ Test 2: (16/20) × 20 = 16.00                       │    │
│  │ Exam:   (54/60) × 60 = 54.00                       │    │
│  └────────────────────────────────────────────────────┘    │
│                                                              │
│  STEP 2: Sum Total                                          │
│  ┌────────────────────────────────────────────────────┐    │
│  │ Total = 18.00 + 16.00 + 54.00 = 88.00              │    │
│  └────────────────────────────────────────────────────┘    │
│                                                              │
│  STEP 3: Calculate Percentage                               │
│  ┌────────────────────────────────────────────────────┐    │
│  │ Max Total = 20 + 20 + 60 = 100                     │    │
│  │ Percentage = (88.00 / 100) × 100 = 88.00%          │    │
│  └────────────────────────────────────────────────────┘    │
│                                                              │
│  STEP 4: Assign Grade                                       │
│  ┌────────────────────────────────────────────────────┐    │
│  │ 88.00% → Grade B (80-89%)                          │    │
│  └────────────────────────────────────────────────────┘    │
│                                                              │
│  OUTPUT: Total, Percentage, Grade                           │
│  ┌────────────────────────────────────────────────────┐    │
│  │ Total: 88.00                                        │    │
│  │ Percentage: 88.00%                                  │    │
│  │ Grade: B                                            │    │
│  └────────────────────────────────────────────────────┘    │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## 🔐 Security Flow

```
┌─────────────────────────────────────────────────────────────┐
│                      SECURITY FLOW                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. User Login                                               │
│     ┌────────────────────────────────────────────────┐     │
│     │ Username: teacher@garden.rw                     │     │
│     │ Password: ********                              │     │
│     └────────────────────────────────────────────────┘     │
│                          │                                   │
│                          ▼                                   │
│  2. JWT Token Generation                                     │
│     ┌────────────────────────────────────────────────┐     │
│     │ Server validates credentials                    │     │
│     │ Generates JWT token                             │     │
│     │ Returns token to client                         │     │
│     └────────────────────────────────────────────────┘     │
│                          │                                   │
│                          ▼                                   │
│  3. Token Storage                                            │
│     ┌────────────────────────────────────────────────┐     │
│     │ localStorage.setItem('token', jwt)              │     │
│     └────────────────────────────────────────────────┘     │
│                          │                                   │
│                          ▼                                   │
│  4. API Requests                                             │
│     ┌────────────────────────────────────────────────┐     │
│     │ Headers: {                                      │     │
│     │   Authorization: `Bearer ${token}`             │     │
│     │ }                                               │     │
│     └────────────────────────────────────────────────┘     │
│                          │                                   │
│                          ▼                                   │
│  5. Server Validation                                        │
│     ┌────────────────────────────────────────────────┐     │
│     │ Verify JWT token                                │     │
│     │ Check role = 'teacher'                          │     │
│     │ Process request                                 │     │
│     └────────────────────────────────────────────────┘     │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```
