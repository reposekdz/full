## 🎯 How to Use

### Option 1: Use Startup Script (Easiest)
```bash
start-comprehensive-system.bat
```

### Option 2: Manual Start
```bash
# Terminal 1 - Backend
cd backend
node server-comprehensive.js

# Terminal 2 - Frontend
npm run dev
```
