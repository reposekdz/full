PROBLEM: Parent redirects to admin dashboard
CAUSE: Role is "student" instead of "parent" in database

═══════════════════════════════════════════════════════════

🚀 FASTEST FIX (Copy & Paste):

1. Open MySQL (phpMyAdmin, Workbench, or command line)

2. Select database: school_management

3. Run this ONE command:

UPDATE users SET role = 'parent' WHERE phone = '0796329328';

4. Restart backend server (Ctrl+C, then npm start)

5. Login again → Should go to Parent Dashboard! ✅

═══════════════════════════════════════════════════════════

📋 VERIFY IT WORKED:
