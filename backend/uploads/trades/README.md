# Trade Images

Place your trade images in this folder with the following names:

- **sod.jpg** - Software Development image
- **bdc.jpg** - Building & Construction image  
- **auto.jpg** - Automotive Technology image
- **default.jpg** - Default fallback image

## Image Requirements:
- Format: JPG, PNG, or WebP
- Recommended size: 1920x1080 (16:9 aspect ratio)
- Maximum file size: 5MB

## Current Images:
The system will automatically load images from this folder and display them on the trades page.
