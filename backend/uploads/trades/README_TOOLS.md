## How to Add More Tool Images

### For SOD (Software Development)
Place images in: `uploads/trades/SOD/tools/`
Examples:
- `javascript.jpg` - JavaScript programming
- `python.jpg` - Python programming
- `react.jpg` - React framework
- `database.jpg` - Database tools
- `cloud.jpg` - Cloud computing

### For BDC (Building & Construction)
Place images in: `uploads/trades/BDC/tools/`
Examples:
- `autocad.jpg` - AutoCAD software
- `construction-tools.jpg` - Construction equipment
- `surveying.jpg` - Surveying tools
- `safety-gear.jpg` - Safety equipment

### For AUTO (Automotive Technology)
Place images in: `uploads/trades/AUTO/tools/`
Examples:
- `diagnostic.jpg` - Diagnostic tools
- `engine-tools.jpg` - Engine repair tools
- `electrical.jpg` - Electrical tools
- `brake-tools.jpg` - Brake system tools

## Image Requirements

- **Format**: JPG, JPEG, JFIF, PNG, or WebP
- **Size**: 800x600 pixels recommended
- **Max file size**: 2MB per image
- **Naming**: Use descriptive lowercase names with hyphens

## Usage

Images in the tools folders will be automatically loaded and displayed in the trade detail pages.
