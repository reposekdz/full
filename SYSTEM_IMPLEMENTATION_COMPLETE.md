## 🎟️ Student Serial Code System

### ✅ Implementation

Students **must have a valid serial code** to register. Serial codes are generated by authorized staff (DOS, Headmaster, Admin, DOD).

### ✅ Serial Code Management Endpoints

**Generate Serial Codes:**
```
POST /api/serial-codes/generate
Authorization: Bearer {token}
Required Role: dos, headmaster, admin, dod

Body:
{
  "trade_code": "ICT",
  "level_number": 1,
  "level_suffix": "A",
  "quantity": 10,
  "expires_at": "2026-12-31T23:59:59Z",
  "notes": "Optional notes"
}
```

**Validate Serial Code:**
```
POST /api/serial-codes/validate

Body:
{
  "serial_code": "ICT1A-ABC12345"
}
```

**List Serial Codes:**
```
GET /api/serial-codes/list
Authorization: Bearer {token}
Required Role: dos, headmaster, admin, dod

Query Parameters:
- status: active|used|expired|revoked
- trade_code: ICT|ELE|PLU|WEL|CAR
- level_number: 1|2|3
- is_used: true|false
- page: 1
- limit: 50
```

**Revoke Serial Code:**
```
PUT /api/serial-codes/revoke/:id
Authorization: Bearer {token}
Required Role: dos, headmaster, admin, dod
```

**Delete Serial Code:**
```
DELETE /api/serial-codes/delete/:id
Authorization: Bearer {token}
Required Role: admin
```

**Get Statistics:**
```
GET /api/serial-codes/statistics
Authorization: Bearer {token}
Required Role: dos, headmaster, admin, dod
```

### ✅ Student Registration Process

1. **Student receives serial code** from DOS/Headmaster when added to a level/trade
2. **Student registers** using the serial code:
   ```
   POST /api/auth/register/student
   
   Body:
   {
     "serial_code": "ICT1A-ABC12345",
     "first_name": "John",
     "last_name": "Doe",
     "email": "john.doe@example.com",
     "phone": "+250788123456",
     "password": "securepassword",
     "date_of_birth": "2005-01-15",
     "gender": "Male",
     "address": "Kigali, Rwanda",
     "emergency_contact": "+250788654321",
     "medical_info": "No known allergies",
     "parent_info": {
       "first_name": "Jane",
       "last_name": "Doe",
       "phone": "+250788111222",
       "email": "jane.doe@example.com"
     }
   }
   ```
3. **Serial code is validated** (active, not used, not expired)
4. **Student account is created** and assigned to appropriate trade/level
5. **Serial code is marked as used**
6. **Parent account is created** (if parent_info provided)
7. **Welcome SMS sent** to student and parent
