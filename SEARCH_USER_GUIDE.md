# 🔍 Search System User Guide

## Quick Start

### Opening Search
There are multiple ways to open the search:

1. **Keyboard Shortcut** (Fastest)
   - Press `Ctrl+K` (Windows/Linux)
   - Press `Cmd+K` (Mac)

2. **Click Search Bar**
   - Click the search bar in the header
   - On mobile: Tap the search icon

3. **Voice Command**
   - Open search and click the microphone icon
   - Speak your query clearly

## Basic Search

### Step-by-Step
1. Open search (Ctrl+K)
2. Type what you're looking for
3. Results appear instantly
4. Click any result to view details

### Search Tips
- **Minimum 2 characters** required
- Results update as you type
- Works in any language
- Case-insensitive

## Advanced Features

### 1. Voice Search 🎤

**How to Use:**
1. Open search modal
2. Click the microphone icon (right side of search bar)
3. Allow microphone access if prompted
4. Speak clearly: "Software Development"
5. Results appear automatically

**Supported Languages:**
- English (en-US)
- Kinyarwanda (rw-RW)
- French (fr-FR)

**Tips:**
- Speak clearly and at normal pace
- Avoid background noise
- Wait for the red indicator to stop

### 2. Filtering Results 🎯

**How to Filter:**
1. Enter your search query
2. Click the "Filter" button
3. Select a category:
   - All Types
   - Courses
   - Trades
   - Exams
   - Sports
   - News
   - Gallery

**When to Use:**
- Too many results
- Looking for specific type
- Browsing by category

### 3. Sorting Results 📊

**Sort Options:**
- **Relevance** (Default) - Best matches first
- **Date** - Newest items first
- **Name** - Alphabetical order

**How to Sort:**
1. Click the "Sort" button
2. Choose your preferred option
3. Results reorder instantly

### 4. Quick Searches ⚡

**Pre-defined Categories:**
- 📚 Amasomo (Courses)
- 📝 Ibizamini (Exams)
- 🏆 Siporo (Sports)
- 🎓 Amahugurwa (Trades)
- 📰 Amakuru (News)
- 📸 Amafoto (Gallery)
- 🛡️ Ubuyobozi (Leadership)

**How to Use:**
1. Open search
2. Click any quick search button
3. Instant results for that category

### 5. Trending Searches 🔥

**What It Shows:**
- Most popular searches (last 30 days)
- What others are looking for
- Hot topics

**How to Use:**
1. Open search (without typing)
2. See trending searches below quick searches
3. Click any trending term
4. View results

### 6. Search History 📜

**Features:**
- Automatically saves your searches
- Stored locally (private)
- Quick re-search
- Last 10 searches saved

**How to Use:**
1. Open search
2. View recent searches at bottom
3. Click to search again

**To Clear History:**
- Clear browser data, or
- Use incognito/private mode

## Troubleshooting

### No Results Found

**Possible Causes:**
1. Typo in search query
2. Content not available
3. Wrong category filter

**Solutions:**
- Check spelling
- Try different keywords
- Remove filters
- Use broader terms
- Try another language

### Voice Search Not Working

**Possible Causes:**
1. Microphone not allowed
2. Browser doesn't support voice
3. No microphone connected

**Solutions:**
- Allow microphone access
- Use Chrome/Edge browser
- Check microphone settings
- Try typing instead

### Slow Search

**Possible Causes:**
1. Slow internet connection
2. Too many results
3. Server busy

**Solutions:**
- Check internet connection
- Use filters to narrow results
- Try again later
- Clear browser cache

### Search Not Opening

**Possible Causes:**
1. JavaScript disabled
2. Browser compatibility
3. Page not loaded

**Solutions:**
- Enable JavaScript
- Use modern browser
- Refresh page
- Clear cache
