## 🎟️ SERIAL CODE SYSTEM

### How It Works:
1. **Generation:** Only DOS, Headmaster, Admin, and DOD can generate serial codes
2. **Format:** `{TRADE_CODE}{LEVEL}{SUFFIX}-{RANDOM}` (e.g., `SOD4A-3D005E92`)
3. **Usage:** Students MUST have a valid serial code to register
4. **Expiration:** Serial codes can have expiration dates
5. **Status:** Active, Used, Expired, Revoked

## 📝 STUDENT REGISTRATION PROCESS

### New Student Registration:
1. **Obtain Serial Code:** Contact DOS/Headmaster/Admin to generate a serial code for your trade level
2. **Register with Serial Code:**
   ```
   POST /api/auth/register/student
   {
     "serial_code": "SOD4A-3D005E92",
     "first_name": "John",
     "last_name": "Doe",
     "email": "john.doe@example.com",
     "phone": "+250788123456",
     "password": "SecurePass123",
     "date_of_birth": "2005-06-15",
     "gender": "Male",
     "address": "Kigali, Rwanda",
     "parent_info": {
       "first_name": "Jane",
       "last_name": "Doe",
       "email": "jane.doe@example.com",
       "phone": "+250788654321",
       "relationship": "Mother"
     }
   }
   ```
3. **Auto-Generated:**
   - Student ID (e.g., `2026SOD4A009`)
   - Parent account (if parent_info provided)
   - Enrollment in appropriate trade class
   - Welcome SMS notifications

## 🔧 PROFILE MANAGEMENT

### All Users Can:
- View their profile: `GET /api/auth/profile`
- Update profile information: `PUT /api/auth/profile/update`
  - Change first name, last name
  - Update email (with uniqueness validation)
  - Change phone number
  - Update address
  - Change password (requires current password)
  - Upload profile image
- View edit history: `GET /api/auth/profile/history`
