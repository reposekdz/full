# DOD Dashboard Advanced - Quick Reference

## 🚀 Quick Actions

### Remove Conduct
1. Find student in table
2. Click 🚫 Ban icon
3. Fill form → Submit
4. Parent auto-notified ✅

### Contact Parent
1. Click 📞 Phone icon
2. Write message
3. Choose SMS/WhatsApp
4. Send ✅

### Bulk Message
1. ☑️ Check students
2. Click "Message Parents"
3. Write message
4. Send to all ✅

## 🔍 Search & Filter

| Feature | How to Use |
|---------|------------|
| **Search** | Type name/ID in search box |
| **Trade Filter** | Select from dropdown |
| **Level Filter** | Select from dropdown |
| **Conduct Filter** | Good/Average/Poor |
| **Clear All** | Click "Clear Filters" |

## 📊 Statistics

| Stat | Meaning |
|------|---------|
| **Total Students** | All students in system |
| **Poor Conduct** | Conduct score < 60% |
| **Poor Attendance** | Attendance < 70% |
| **Total Incidents** | All recorded incidents |

## 🎨 Color Codes

### Conduct Badges
- 🟢 **Green** (≥80%): Good conduct
- 🟡 **Yellow** (60-79%): Average conduct
- 🔴 **Red** (<60%): Poor conduct

### Attendance Badges
- 🟢 **Green** (≥90%): Excellent attendance
- 🟡 **Yellow** (70-89%): Good attendance
- 🔴 **Red** (<70%): Poor attendance

## ⚡ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl + F` | Focus search box |
| `Ctrl + R` | Refresh data |
| `Esc` | Close modal |

## 🔧 Conduct Types

| Type | When to Use |

## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
