# 👨👩👧 Parent Portal Interactive - Quick Reference

## 🚀 30-Second Setup

```bash
setup-parent-portal-interactive.bat
cd backend && npm start
```

## 🔑 Access

**URL:** `http://localhost:5173/parent-dashboard-interactive`

**Login:** Use parent phone number and password

## 📊 Features at a Glance

| Feature | What You Can Do |
|---------|----------------|
| **Dashboard** | View summary of all children |
| **Conduct** | Monitor behavior incidents |
| **Attendance** | Track daily attendance |
| **Grades** | View academic performance |
| **Fees** | Check balance and make payments |
| **Assignments** | See homework and submissions |
| **Leave** | Submit leave requests |
| **Messages** | Chat with teachers |
| **Notifications** | Get real-time alerts |

## 🎯 Quick Actions

### View Child's Conduct
1. Select child
2. Click "Conduct" tab
3. View all incidents

### Check Attendance
1. Select child
2. Click "Attendance" tab
3. See attendance rate

### Submit Leave Request
1. Navigate to Leave Requests
2. Fill form
3. Submit

### Message Teacher
1. Go to Messages
2. Select teacher
3. Send message

## 📱 Mobile Access

Fully responsive - works on all devices!

## 🔔 Notifications

You'll receive alerts for:
- Conduct incidents
- Low attendance
- Grade updates
- Fee reminders
- Assignment deadlines

## 💡 Tips

- Check dashboard daily
- Enable notifications
- Respond to messages promptly
- Monitor conduct score
- Track fee balance
