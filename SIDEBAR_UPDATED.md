- **Windows**: Press `Ctrl + Shift + R`
- **Mac**: Press `Cmd + Shift + R`

### 2. Restart Dev Server
```bash

# Then restart:
npm run dev
```

### 3. Clear Browser Cache
- Open DevTools (F12)
- Right-click the refresh button
- Select "Empty Cache and Hard Reload"
